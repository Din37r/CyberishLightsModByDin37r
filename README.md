About
---
  This mod adds two new types of light sources to the game: **Neon Lamps** and **Neon Lanterns**. Each has 16 versions for all colors.
  
  **Neon lamps** require a redstone signal to produce light, and basically work the same as vanilla redstone lamps.
  
  **Neon lanterns** can be placed on blocks, they do not require support in order to stay up.
